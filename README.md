# HERO: Hierarchical EEG Representation with Ordinal Graph Learning for Task-Evoked Autism Severity Grading

This repository provides the implementation and experimental materials for **HERO**, a hierarchical EEG representation learning framework for task-evoked autism spectrum disorder (ASD) severity grading. The project focuses on EEG signals collected during game-based assessment tasks and formulates ASD assessment as an ordinal severity grading problem.

The repository contains the proposed HERO-related code, comparison methods, experimental materials, and partial game sequence documentation.


For questions about the code, experimental setting, or data access, please contact the corresponding author.

The original dataset may be available upon reasonable request, subject to ethical approval and data-use agreement.
